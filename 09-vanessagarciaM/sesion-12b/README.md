## apuntes sesión

### retroalimentación y orientaciones para el proyecto 03

durante la clase se realizó una instancia de retroalimentación de nuestros proyectos 02, en la que se revisaron distintos aspectos por mejorar y se entregaron recomendaciones para las próximas etapas del trabajo.

misa hizo especial énfasis en la importancia de utilizar correctamente las citas y referencias bibliográficas desde el comienzo del proyecto, ya que dejar esta tarea para el final podría generar dificultades durante el seminario sos. se destacó la necesidad de respaldar la información del marco teórico y los referentes utilizados, acreditando las fuentes correspondientes y citándolas correctamente. además, se recalcó que no basta con incluir referencias, sino que también es importante argumentar las decisiones tomadas y explicar el porqué de cada una. para facilitar este proceso, se recomendó utilizar el software zotero como herramienta de gestión bibliográfica.

también se abrió un espacio para conversar sobre las dudas, experiencias y aspectos que nos han gustado o no del desarrollo del proyecto. junto con esto, se explicaron los requisitos y las distintas posibilidades para el proyecto 03:

- cada clase contará con entregables pequeños que serán evaluados durante el proceso.
- se mantendrán los grupos de cuatro integrantes.
- no se incorporará más contenido teórico tradicional, sino que se trabajará mediante pequeñas cápsulas de aprendizaje.
- el uso de un parlante será obligatorio.
- la incorporación de una pantalla será opcional.
- se podrán desarrollar máquinas que emitan sonidos, con la posibilidad de incorporar un micrófono para grabar audio y reproducirlo posteriormente.
- si se utiliza un parlante, no será necesario incorporar un buzzer.
- no se permitirá utilizar el chip 386.

### comentarios y aspectos por mejorar del proyecto 02

finalmente, recibimos comentarios específicos sobre nuestro proyecto 02, los cuales nos permitirán identificar los puntos débiles y realizar mejoras de cara a la siguiente entrega. entre las principales observaciones se mencionaron:

- complementar y mejorar la descripción de los componentes utilizados.
- revisar y desarrollar de mejor manera la propuesta de interfaz adversarial.
- ampliar la documentación del proyecto, incorporando información más detallada.
- incluir y mejorar el esquemático del circuito.
- corregir errores ortográficos y revisar la redacción general.
- incorporar diagramas de flujo que permitan explicar de manera más clara el funcionamiento y los procesos del proyecto.

esta retroalimentación nos permitió tener mayor claridad sobre los aspectos que debemos fortalecer, tanto en la documentación como en el desarrollo y presentación de nuestro próximo proyecto.
