# proyecto-tres

## rúbrica

tiene 3 criterios grupales y 3 criterios individuales.

cada criterio se evalúa entre 0.0 y 1.0, con un decimal de resolució.

la nota de proyecto dos se calcula como la suma de esos 6 puntajes, más el punto base.

- criterio-01: grupal. documentación textual y diagramática. README del proyecto, diagramas de flujo, esquemáticos, prompts usados, proceso.
- criterio-02: grupal. factiblidad. bill of materials, simulaciones en wokwi, pseudocódigo, coreografía. detallar alcances técnicos logrables y desechados.
- criterio-03: grupal. referentes (cantidad 10). bibliografía, análisis de referentes, incluyendo diseñadores, artistas, proyectos, instalaciones, obras, instrumentos, etc.
- criterio-04: individual. presentación oral del proyecto, incluyendo relato y responder preguntas.
- criterio-05: individual. bitácoras, incluyendo encargos y lecturas
- criterio-06: individual. tiempo. ensayo de 1 página sobre su relación con el tiempo, sobre la mañana y la hora de clases, sobre el paso del tiempo, el uso del tiempo, la política y el tiempo. hacer en google docs y compartir link en bitácora.
